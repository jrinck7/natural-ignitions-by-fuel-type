# Data

`data/` is gitignored — it holds ~6.9 GB, far past what belongs in a repo. Nothing
here is backed up. That is deliberate: every file is either a public download or
is regenerated by a notebook in `notebooks/`. This file is the recipe for
rebuilding the folder from nothing.

All paths are relative to the repo root. Notebooks run from `notebooks/`, so they
refer to these as `../data/...`. **`QGIS/Project2.qgz` also loads several of these
by relative path** (`../data/...`), so the `QGIS/` and `data/` folders must stay
siblings or the map will open with broken layers.

## Source data — download these

| Folder | Dataset | Source | Size |
|---|---|---|---|
| `FPA_FOD/FPA_FOD_20260615.gpkg` | Spatial wildfire occurrence data for the United States, 1992–2024 (**7th Edition**), USFS. 2.3 M geo-referenced records: discovery date, final size, point location (~1 sq mi accuracy), cause. | https://www.fs.usda.gov/rds/archive/catalog/RDS-2013-0009.7 | 1.1 GB |

| `glmmth/GLMc_th_2019.nc`, `GLMc_th_2020.nc` | Combined Geostationary Lightning Mapper (GLM) Hourly Thunder Hour Data Product, NASA GHRC DAAC (collection `C3894650367`). | https://search.earthdata.nasa.gov/search/granules/collection-details?p=C3894650367-GHRC_DAAC | 1.2 GB |
| `ecoregions/us_eco_l3_state_boundaries.shp` | Level III Ecoregions of the Conterminous United States, EPA. 85 Level III regions. | https://www.epa.gov/eco-research/level-iii-and-iv-ecoregions-continental-united-states | 47 MB |

Earthdata downloads need credentials. The container sets them up via
`gds-project2/10-earthdata-netrc.sh` (writes `~/.netrc`); see that script before
fetching GLM data.

The 6th Edition of FPA-FOD (1992–2020,
https://www.fs.usda.gov/rds/archive/catalog/RDS-2013-0009.6) was used earlier in
the project, and InFORM (https://in-form-nifc.hub.arcgis.com/pages/in-form-faqs)
is noted as a backup wildfire source. Neither is required to rebuild `processed/`.

### Known inconsistency

`notebooks/Project2_Launch_JansenRinck.py:147` reads
`../data/processed/fire_natural_2019_2020.gpkg`, which **does not exist** in
`processed/`. That notebook will fail at this cell until the file is rebuilt or
the path is corrected.

## Rebuilding from scratch

1. Download the four source datasets above into the folder names in the table.
2. Run `notebooks/Project2.ipynb` top to bottom — writes four of the six
   `processed/` files.
3. Run `notebooks/Project2_personal.ipynb` — writes
   `dominant_fuel_group_5.1km_sigma.tif`.
4. Open `QGIS/Project2.qgz` and confirm all layers resolve.

Notebooks are jupytext-paired: `.ipynb` is gitignored and the `.py` is the tracked
copy. Regenerate a notebook with
`jupytext --to notebook notebooks/<name>.py`.
